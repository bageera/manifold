# MNF-HP1 — Native conditional-information census record

Program: MNF-HP. Question per the gauntlet §20: what information does the
production probability model fail to capture that the decoder can still
reach? Measured directly against the production mix coder's own P0 (backends
4–7, exactly as replayed by the HP0-verified in-crate instrument).

Population: 29/30 corpus images traced byte-exactly (blocks_192x128 is a
token-picked wire — no lane geometry, skipped by design). 7 zstd/zlib-picked
fixtures carry labeled statistical-family replay controls; 22 are genuine
mix-backend winner streams. Held-out rule: `heldout-photos/*` never
contributes counts.

## 1. Instrument and acquisition (MEASURED)

`src/mix_coder.rs::mnf_hp1_census_dump` (env-gated `#[ignore]`): for each
image, decodes the production pick's own header flags, rebuilds the winner
arm's record stream (`build_record_stream` + REF relabel), asserts BYTE-EXACT
reconstruction of the assembled production file, then replays the production
model in lockstep (mix_ctx_key + probs_with + step + share_step; LaneWalk
class parity asserted per byte) and emits per-byte traces:

- y, P0 aggregates (fixed-point py at 2^24, rank of y, entropy×256, pmax);
- spatial neighbors at distances 1/2/4/8/16/32 with validity bits, diagonal;
- cross-lane same-position bytes (pa/pb) with validity bits;
- record mode, tile-local coordinates, tile dimensions;
- per-image 40k-row prefix dumps of the full 256-slot P0 vectors (u32 LE).

Acquisition parity: rebuilt stream fnv == N1 ledger identity on overlapping
fixtures (terrain `bc3e42c1ec950cd7`, forest `f87a3e74824317f0`, screenshot
`c04130a2d860f5a4`, gradient `e7fc0ca6baaa566d`); ideal-bit totals equal the
independent MNF17-N2 A1 replay to the decimal. Traces:
`research/results/hp1-native-traces/` (gitignored; regenerated by the
committed instrument; ledger.csv inside).

## 2. Measurement method

Corrector: interpolated mixture `Pθ(y) = (1−λ)·P0(y) + λ·C(b,F,y)` with C a
Laplace-smoothed (confidence-bucket, feature-bin, symbol) count table,
b = 16 buckets over the model's PRE-SYMBOL entropy (decoder-available; the
first draft's bucketing on P0(y) itself was a symbol leak — caught and fixed
before any conclusion), F one census feature. Counts from TRAIN images only;
λ from a 20% train subsample; gain = Σ log2(Pθ/P0) bits on held-out
heldout-photos (positive = fewer bits than production P0). Controls: null
(b-only table), AX (feature values shuffled across rows keeping (b,y) pairs —
the row-level permutation used in the first draft was broken and reported
identical gains; fixed), AN (random feature). Census CSV:
`research/results/hp1-feature-census.csv`.

families (per-image std ±2 spans zero).

## 4. Class-matched + refinement pass (HP1b, MEASURED)

`research/hp1/census_classmatch.py`: photos-only training → heldout-photos
(no cross-class pooling), plus relation-shaped features the width-32 value
bins could not express (equality indicators `l1==u1`, `u1==dg`, flatness
`|e|≤2 ∧ |s|≤2`, fine signed e at width 8).
`research/results/hp1b-classmatched-census.csv`:

- X_lu / X_ud / X_flat: **+5.05–5.11 bits/krow** held-out (λ*=0.10), positive
  aggregate, per-image min −10.69 / max +10.29 / std 6.36 — real but small
  (≈ 0.2% of the test pool payload) and NOT reproducible on every image;
- X_e8 (fine 33-bin signed difference): −0.58/krow — overfit boundary.

Three sibling definitions of one binary "local flatness/duplication" signal
converge to the same +5/krow — the only reproducible conditional information
found anywhere in the census.

## 5. Disclosed iterations

1. First draft bucketed confidence on P0(y) (symbol leak) and permuted whole
   rows (control inert). Both defects produced the inflated "+100/krow"
   table now superseded; every number above is from the corrected
   instrument. The leak fix and re-run happened before any HP1 verdict was
   recorded.

## 6. Gate disposition

Gate HP1 ("at least one feature family demonstrates reproducible incremental
predictive information on held-out data"): **CONDITIONAL PASS at marginal
strength** — the HP1-B equality/flatness family clears the bar only under
class-matched training, at ≈ 0.2% payload scale, with per-image sign
flips. All other branches close **NEGATIVE**. No branch justifies expanded
model capacity (HP3–HP7 entry conditions unmet except for the flatness
survivor handed to HP2).

## 7. Limits

- Census features are byte-granular and single-feature; interactions are not
  probed (deliberate: smallest model first).
- zstd-picked fixtures enter only as labeled replay controls; production
  wire sizes are HP0 §3's.
- The census measures PROBABILITY improvement, never wire size; model-inclusive
  economics are HP2's gate and are reported there.
